Excel Mini Project
Overview
This repository contains a hands-on Excel project dataset (Mini_Project.xlsx) designed to analyze key metrics, perform data cleaning, and visualize trends using fundamental and advanced Excel functions.

Features & Highlights
Data Organization: Structured spreadsheet setup for clear, readable analysis.

Excel Functions & Formulas: Usage of formulas (e.g., SUM, AVERAGE, VLOOKUP/XLOOKUP, IF logic) to automate calculations.

Data Visualization: Charts and tables to highlight key insights and summary statistics.

File Structure
Plaintext
├── Mini_Project.xlsx    # Main Excel workbook containing datasets and analysis
└── README.md            # Project documentation
How to Use
Download or clone the repository to your local machine.

Open Mini_Project.xlsx using Microsoft Excel, Google Sheets, or any compatible spreadsheet software.

Explore the individual worksheets to review the formulas, calculations, and visual summaries.
